WHISPER / TERMINAL

安装一次，之后直接 whisper。

服务由朋友的电脑提供。你在自己的 PowerShell 安装和使用 CLI，不用启动服务器，不用单独安装 Node.js、npm 或 Git。

1 / 首次安装或更新

Windows x64 · 当前用户安装 · 不需要管理员权限

只执行你信任的服务提供者给出的命令。它会下载并校验安装脚本和客户端、自动解压，再添加用户 PATH；不修改系统执行策略。

2 / 在 PowerShell 连接聊天



安装成功后即可在同一窗口运行上面的命令。以后可以直接输入 whisper 连接安装时保存的服务地址。


临时网址变化时，只需换成新地址执行 whisper --server 新地址，无需重新安装。


3 / 登录与使用
/register 邀请注册，/login 登录；再输入 /chat 对方用户名。输入文字，按 Enter 发送。


账号与网页共用，图片仍在网页查看。密码在客户端提示中隐藏输入，不放进安装或连接命令。


卸载命令：whisper --uninstall。卸载默认保留公钥核对记录，不清空聊天服务器。


安装包只是命令安装的内部载荷，无需手动解压。此原型未经安全审计、无前向保密，无法防截屏与终端录制。校验哈希不等于发布者签名。电脑关机或隧道停止后，服务不可用。
