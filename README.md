# Whisper

一个申请审批制的双人聊天实验项目，提供网页、Windows / Linux CLI 和安卓客户端。
消息在发送者设备加密、接收者设备解密；服务端负责账号、权限、密文转发和限时存储。

当前源码版本为 **0.6.2**。本文描述源码行为；正式服务版本、发布验收与手机安装状态以实际验证为准，云端记录见 [部署手册](cloud/DEPLOYMENT.md)。

0.6.2 网页、Android、Windows / Linux CLI 在发送文字时立即清空输入，密文按提交顺序排队，可继续输入下一段；队列只存在当前进程内，至多 20 条，不自动重发结果不明的上传。切换会话、退出或身份变化会取消尚未发出的队列；程序结束不会保存待发文字。网页 / App 的失败消息在原期限内提供“放回输入框”，保留新草稿；CLI 通过状态栏报告失败和同步核对提示。图形界面使用垃圾桶按钮删除消息，仍需确认；文字到期 / 删除和三秒阅后图片先清除内容，再用约半秒尘粒效果消散。开启减少动画时直接清理。CLI 保留 `/delete 消息序号`，销毁时短暂显示字符消散提示。

Windows / Linux 已安装 0.6.1 后，退出 CLI，在终端执行 `whisper update`，再用 `whisper` 聊天；更新有进度与英文成功提示，保留公钥核对记录和受保护登录。更早版本先从 [CLI 安装页](https://whisper.leonz03.dpdns.org/cli) 重新安装一次。

Android 0.6.1 启动后低频检查更新，也可点“我的 → 应用版本”检查、下载并打开系统确认安装。版本清单和 APK 都从正式站下载，手机不依赖访问 GitHub；[GitHub Releases](https://github.com/LeonZ03/Whisper/releases) 同时提供同一签名 APK。旧 App 首次需覆盖安装 0.6.1，禁止先卸载或清空应用数据。App 内更新会核对 SHA-256、包名、递增版本码和原签名后才进入安装流程。仍使用同一身份和加密协议，本版本没有新增数据库迁移。

**这是未经安全审计的个人原型，不承诺完全匿名、前向保密、防截图或远程彻底擦除。请先使用非敏感内容。**

## 安卓 APK

安卓客户端按确认稿使用 W 图标和森林绿，提供登录、会话、聊天及“我的”，与正式网页、CLI 共用云端账号。Android 8.0 及以上、更新后的系统 WebView 可运行。

运行 `npm.cmd run build:android` 按当前源码版本生成 `public/downloads/whisper-android-0.6.2-r1.apk`，传到手机后点开覆盖安装；构建命令和文件名不代表手机已安装更新。应用启用 Android 系统截图、录屏和最近任务预览限制；不能阻止另一台设备拍照、受控系统或网页端留副本。登录状态由安卓密钥库加密保留，切后台、结束进程和重启不需重新输入密码；后台清除显示中的消息与图片。重启直接进入会话界面，后台验证登录并同步列表，断网时保留界面并提供重试。显式退出清除保存的登录。改密、恢复、账号禁用或超过八个有效登录会话仍可撤销登录。

“我的”在“账号”下显示已登录设备卡片，只展示当前设备名称和“本机”；点开查看可上下滑动的登录记录，最多保留每账号最近 10 次成功登录，包含网页 / App / CLI 方式、登录和退出时间、最近连接 IP 与估计地区。退出、到期或撤销后的记录仍占这 10 条；有效登录不表示设备实时在线。服务、应用版本和隐私入口不再使用外框。旧会话由对应设备再次连接时补齐元数据；IP 是最近连接的网络出口，不代表最初登录时的 IP，也无法恢复升级前已删除的记录。

0.5.3 需要独立应用 `0003_session_devices.sql`；0.5.5 新增 `0004_login_history.sql` 保存有数量上限的登录历史。两者都保留原会话列，不重建账号或聊天表。历史记录上限与八个有效会话上限相互独立。本机服务启动时原子升级自己的数据库；云端迁移须按[部署手册](cloud/DEPLOYMENT.md)由所有者审核后单独执行。

0.5.6 复用上述表，不新增数据库迁移，也不延长已有会话。

安装、构建、签名密钥备份与验证范围见 [安卓说明](android/README.md)。APK 不自动部署网页或修改云端数据。

## 能做什么

- 提交账号申请、经所有者审批后登录，按完整用户名建立固定双人会话，没有群聊。
- App、网页和 CLI 连接同一服务时，共用账号、身份密钥及未到期消息，可以互相聊天。
- 文字保留时间可选 1 分钟、1 小时、24 小时、7 天；三端均显示实时倒计时。
- 消息到期或双方删除时，网页和 App 先清除正文，再用不含内容的空壳和小粒子做短暂消散；支持系统减少动态效果设置。
- 网页和 App 支持一次查看图片：原图上限 20 MB，设备会缩放并压缩到不超过 1 MB 后再加密上传；无法压缩到限制内时会提示换较小图片。接收方打开后最多显示 3 秒，再清除图片并显示短暂消散动画；未打开最多保留 24 小时。GIF 会变为静态图片，CLI 不领取图片。
- CLI 支持颜色、`/` 前缀菜单、上下键命令回溯、聊天历史分页和不覆盖聊天的帮助输出。

## 四端账号入口与登录保留

| 功能 | 网页 | Android App | CLI |
| --- | --- | --- | --- |
| 账号与当前设备 | “我的” | “我的” | `/me` |
| 修改密码 | “我的”→账号 | “我的”→账号 | `/passwd` |
| 最近十次设备登录 | “我的”→已登录设备卡片 | “我的”→已登录设备卡片 | `/devices`，在终端记录内翻阅 |
| 当前服务与版本 | “我的”→服务、关于 | “我的”→服务、关于 | `/me`；启动参数 `--version` 查看客户端版本 |
| 隐私与边界 | “我的”→关于 | “我的”→关于 | `/privacy` |
| 显式退出 | “我的”→退出登录 | “我的”→退出登录 | `/logout` |

设备历史只允许当前账号查看，最多保留最近十次成功登录；包含方式、状态、登录 / 结束时间、最近连接 IP 和估计地区，退出后仍保留。它与每账号八个有效会话上限分别处理，root 原有登录审计不受十条限制。图形界面可滚动；CLI 输出追加在当前聊天记录内，仅自己可见，不发送给联系人、不覆盖聊天。

四端仅在具备相应保护时保留登录（表中的 CLI 同时包含 Windows 和 Linux）：

- 网页在安全上下文中，使用浏览器不可导出的 AES-GCM 密钥保护身份，并将密钥对象与身份密文保存到当前网址的 IndexedDB；会话 cookie 仍由浏览器管理并保持 HttpOnly。这不是硬件隔离，也不能抵挡已控制该页面的恶意脚本。关闭页面清除当前解锁状态，重新打开先向服务核验已保存的登录；浏览器存储不可用时会提示并使用临时登录。
- App 使用 Android Keystore 加密保存 cookie 与身份私钥；后台清除显示内容，重新打开先核验登录。
- Windows CLI 使用当前 Windows 用户的 DPAPI 加密 cookie 与身份私钥；Linux CLI 使用 Secret Service 密钥环中的随机密钥加密本机登录文件。`/quit` 或关闭 CLI 保留受保护登录，`/logout` 清除保存并向服务请求撤销。对应保护不可用时提示临时登录；Linux 密钥环暂时锁定时保留密文供解锁后重试，纯 SSH 环境通常需重新登录。

保存内容不包含原密码、authKey 或聊天正文，不保存明文私钥或明文 CLI cookie。显式退出立即清理本机保存，服务端撤销需退出请求成功；改密、成员恢复、凭据版本变化、账号禁用和会话数量上限仍会使登录失效。保存登录不保证永久可用，清理浏览器站点数据、cookie 到期或保护存储丢失后需要重新登录。

0.5.6 仅在客户端明确发送 `persistent: true`、且账号不要求首次改密时，为网页 / CLI 新登录启用长期会话。旧客户端没有这一标记时仍为十二小时；已有会话保持原期限。详细终端说明见 [CLI.md](CLI.md)，保护范围见 [安全说明](SECURITY.md)。

## 服务提供者：本机启动

开发及已验证运行环境为 Windows x64、Node.js 24+、npm；公网入口还需要安装 cloudflared。
浏览器测试使用 Microsoft Edge。客户端打包需要有效签名的 Windows Node.js 运行时。

```powershell
git clone git@github.com:LeonZ03/Whisper.git
cd Whisper
.\start.cmd
```

首次启动会在项目内安装依赖、构建网页并准备 CLI 发布包，然后启动本机服务和 Cloudflare 临时隧道。
如果客户端打包失败，网页服务仍会尝试启动；查看报错后运行 `npm.cmd run build:cli` 单独排查。

启动窗口会显示本机地址（默认 `http://127.0.0.1:8787`）、临时 HTTPS 网址和朋友使用的 CLI 安装/连接命令。
同样的访问信息在 `data/access-info.txt`；CLI 命令单独写到 `data/cli-commands.txt`。
**本机地址和临时网址访问同一个本机实例。** 朋友只能用公网地址，他的 `127.0.0.1` 指向他自己。

停止服务运行 `.\stop.cmd`，或在启动窗口按 Ctrl+C。仅本机、不建立公网隧道：

```powershell
.\start.cmd --local-only
```

仅对于上述本机＋临时隧道模式：电脑关机、休眠、断网后外部无法访问该本机实例。正式云端域名不受影响；每次重建临时隧道网址可能变化。
不要把“隧道已连接”当成所有访问者都已能打开网页。临时隧道没有可用性保证，也不是永久云端托管。

## 使用网页

打开网址，提交账号申请（用户名 3–24 位小写字母、数字或下划线）。申请无需邀请码；管理员批准后才能登录。新设密码为 1–12 个 Unicode NFC 规范化码点。极短密码很容易被猜中，请尽量使用较长且不重复的组合。已有账号可继续用原密码登录；修改密码时须设置符合新规则的密码。
双方各用自己的账号，在左侧输入对方完整用户名；首次聊天应通过当面或其他可信渠道核对完整安全码。
同一电脑测试两个账号，用两个浏览器或普通窗口加无痕窗口，不要用同一网址的两个普通标签页。
输入消息，Enter 发送，Shift+Enter 换行；下方选择的是新消息的保留期限，不是预约发送时间。
发送时先显示“发送中”，服务端确认后显示“已发送，正在同步”；网络失败不会把待发消息伪装成已送达。新版前台通过实时通知拉取变化，后台页面恢复到前台时重新连接并补拉遗漏。

App 与 CLI 也使用发送中、服务确认后的反馈；“已发送”表示服务已接收，不表示对方已阅读。CLI 网络中断导致结果不明时，会提示先 `/refresh` 核对，避免立即重发造成重复。

每条消息旁显示剩余时间；一分钟内变为黄色、十秒内变为红色。到期按绝对时间清理，不因刷新、后台恢复或动画重新计时。
单条“双方删除”与“双方清空”只约束正常客户端，不能清除截图、导出和其他人保留的副本。

## 管理员初始化与账号维护

每个本机或云端实例分别初始化自己的 `root`。本机服务先启动一次以创建数据库，随后停止服务；在仓库目录运行 `node scripts/manage-root.mjs --local`。云端运行 `node scripts/manage-root.mjs --cloud`。工具会要求交互确认，首次密码固定为 `0000`，并在 `data/` 写出随机名称的私密一次性激活码文件。首次登录网页时使用该激活码，随后立即修改密码。妥善保管并在完成后删除激活码文件。

已建立 root 的实例不要重复运行初始化命令；云端实际状态见[部署手册](cloud/DEPLOYMENT.md)。忘记密码时才由所有者运行云端 `--recover` 命令。本机 root 仍需按本机环境单独建立。

成员申请通过后，root 可批准、拒绝、移除账号，或签发一次性恢复码。恢复码只显示一次，应通过私下渠道交给本人。成员忘记密码恢复会生成全新身份密钥并封存旧会话；旧消息无法解密，联系人需要重新核对安全码。root 本身只能由所有者在服务器/仓库维护环境运行 `node scripts/manage-root.mjs --local --recover` 或 `node scripts/manage-root.mjs --cloud --recover` 恢复；这会撤销 root 会话、重置 root 身份并产生新的激活文件。

账号移除是软删除：撤销登录、封存会话并保留身份墓碑；消息密文按原期限清理，不承诺数据库历史副本立即消失。root 登录记录保存到达应用的 root 尝试时间、IP 与估计位置；位置只是网络估计，不代表住址。失败计数使用账号范围摘要，应用运行中的限流会临时使用来源 IP。不要把申请说明当作端到端加密内容。

## 朋友：安装 CLI 和聊天

Windows x64 用户在自己的 PowerShell 执行启动窗口给出的完整安装/更新命令；Linux x64 / ARM64 用户在 Bash 执行 Linux 命令。也可以从当前公网网址的 `/cli` 选择平台并复制。
Windows 安装到 `%LOCALAPPDATA%\WhisperCLI`；Linux 安装到 `~/.local/share/WhisperCLI`，入口为 `~/.local/bin/whisper`。Linux 需要 Bash、curl、tar 和 sha256sum，支持 glibc 2.28 及以上的常见发行版。
无需管理员权限，无需全局 Node.js/npm/Git；不需要运行服务器，也不是 SSH 登录服务提供者的电脑。只执行来自可信提供者的命令；SHA-256 校验不能证明发布者身份。

```powershell
whisper --server https://实际的当前公网网址
whisper                 # 使用安装时保存的地址
whisper --version       # 检查已安装版本
whisper --no-color      # 单色界面
whisper --uninstall     # 卸载客户端，默认保留公钥核对记录
```

网址变化只需替换 `--server`，不必重装；客户端升级时重新执行最新安装命令。退出 CLI 不会关闭聊天服务。

进入后 `/register` 提交申请，获批后 `/login`；用 `/chat 用户名` 选择联系人，直接输入文字发送。`/help` 查看命令，`/me` 查看账号、设备、服务和版本，`/devices` 查看设备历史。`/quit` 保留受保护登录并退出客户端；要退出账号请用 `/logout`。完整命令及交互说明统一见 [CLI.md](CLI.md)。

输入 `/` 显示菜单，↑↓ 选择、Enter 确认；没有菜单时 ↑↓ 回溯当前会话的有效命令，不记录聊天正文或密码。
鼠标滚轮、PageUp/PageDown 翻阅聊天；Ctrl+End 回底部；Ctrl+J 换行。详细说明见 [CLI.md](CLI.md)。

## 安全与使用边界

使用 libsodium 认证加密原语，但整体协议未经安全审计，没有 Double Ratchet、前向保密或后量子保护。
私钥以密码派生密钥加密后保存在服务器；数据库被盗可遭离线猜密。成员恢复会替换身份，不能找回旧身份密钥或旧消息。
服务器或发布代码被篡改、终端被控制、恶意扩展、录屏或截图都可能泄露内容。删除动画只是界面反馈，不代表物理擦除。
服务端与转发商仍可能看到 IP、时间、大小和通信关系等元数据。昵称不等于匿名网络。
本项目未完成公开运营所需的合规流程；小范围、免费和使用加密不自动免除适用义务。尚未为原创代码指定开源许可证。

## 云端维护命令

```powershell
npm.cmd run build:cloud    # 构建云端网页、Worker、可跨平台生成的 Windows CLI 载荷
npm.cmd run test:cloud     # 真正的 workerd/D1 隔离测试，不连接生产库
npm.cmd run deploy:cloud:code # 仅发布代码，不运行数据库迁移
npm.cmd run db:migrate:cloud  # 单独审核迁移后才运行
```

D1 历史恢复可能保留删除前的密文；界面到期和活动表删除不等于历史备份立即消失。
恢复数据库前必须暂停公开访问并处理被恢复的已删除/已领取内容，不能直接把旧备份重新上线。
未开通付费套餐；云端请求、CPU、数据库额度仍有限，不能承诺永久免费或无限使用。

普通自动部署只运行 `npm run deploy:cloud:code`，不会给每次代码推送附带数据库写入/迁移权限。
数据库结构有变更时，由所有者审核后单独运行 `npm.cmd run db:migrate:cloud`，再发布兼容代码。
云端构建的 Node.js 版本在 `.node-version` 固定为 24.16.0。
