# 闪图预览迁移审核

迁移：`migrations/0006_image_previews.sql`。所有者于 2026-10-23 单独批准后已应用正式 D1；Wrangler 报告 8 个命令成功，随后确认没有待应用迁移。迁移后旧 Worker 仍正常返回 0.6.2 与 `b6a8db31130e2d6b55fb7ddd816dec6e896101b2`。新版代码及 APK 的发布状态见 `DEPLOYMENT.md`。

- 给 `messages` 增加 `preview_nonce`、`preview_ciphertext` 两个可空字段。已有消息填空，不重写原图，不改变账号、会话、密钥、口令或到期时间。
- 预览是在发送端采样的最多 8×8 RGB 色块，使用现有 libsodium 消息加密和独立随机 nonce。加密载荷绑定用途、消息 ID、双方身份、会话与绝对到期时间；服务端只收密文。
- 预览最多 2048 字节密文（Base64 后最多 2732 字符），计入原有 300,000,000 字节存储预算，不扩容。它增加少量传输、D1 写入与存储；空闲时没有预览扫描或额外请求。
- 图片领取仍使用原有 `DELETE RETURNING` 及同语句触发器。`consumed_at` 更新时同步清空预览；删除/过期删除整条消息也删除预览。预览不会包含或提前领取原图。
- 旧图片没有预览，保留占位卡和单次打开；旧客户端忽略新增字段。旧 Worker 使用明确列名写入，迁移后仍能写入与领取图片；旧 Worker 领取也会触发预览清理。

兼容性验证使用独立 SQLite / Miniflare D1：原数据与存储计数不变、旧显式列写入、单赢家领取、预览清理、增量同步、原存储上限。没有连接真实聊天数据库。

发布顺序：所有者审核此文件 → 单独应用 `0006` → 检查现行 Worker 健康 → 发布新版代码和客户端。普通 Cloudflare Builds 仍为代码部署，不应用迁移；不扩大构建令牌权限。代码可回滚到上一版本而保留新增字段及触发器；不要删除列、回滚数据或重建表。

预览本身会让接收方看到粗略颜色和布局，可以被保存；马赛克不等于内容完全保密。三秒单次领取是正常客户端行为，不保证收件方没有保留原图或其他副本。参见 `../SECURITY.md`。
