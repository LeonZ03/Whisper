隐私与边界

这是一个小型私人实验原型，未经安全审计，不是经过审计的安全通信产品。

Android 应用已启用系统截图、录屏与最近任务预览保护；这无法阻止其他手机拍照，也无法限制受控设备。

服务可能看到 IP 地址、访问时间、通信关系及流量等元数据；申请验证消息也可由管理员和服务器读取。

成员恢复会创建新身份并封存旧会话，旧身份私钥无法恢复，因此旧聊天内容也无法解密。

应用进入后台时会清除显示中的消息和图片；登录状态使用安卓密钥库加密保留，显式退出会清除登录状态。网络中断会清空消息视图，但不代表密钥已锁定。
